# engine

LÖVR 0.18 window on the Source-unit proof core. This is not Garry's Mod and not VPhysics.

## Run

```sh
engine/run.sh                         # flat window, gm_construct if the Steam install is present
ENGINE_MODE=stereo engine/run.sh      # two eye renders of that map, side by side
ENGINE_MAP=/path/to/map.bsp engine/run.sh
ENGINE_MAP=none engine/run.sh         # builtin colored room
ENGINE_SHOT=1 engine/run.sh           # one frame of the default map, qa/out/map.png
engine/qa/capture.sh                  # red-sphere eye pair + OpenCV check
luajit engine/tests/run.lua           # offline proofs, no window
```

The LÖVR binary is `engine/.cache/lovr.AppImage` (not in git). `run.sh` always passes `--simulator`, so it does not open WiVRn or change the OpenXR active runtime.

WASD moves. Hold the left mouse button to look. Space jumps. The player tick is `pure/move.lua`. A crate in the builtin room uses `pure/vphysics.lua`.

## What a green capture means

`qa/capture.sh` draws one red sphere from two cameras half an IPD apart and checks the pixel shift against `f * ipd / depth`. The simulator itself has one view. The two PNGs are the stereo pair.

## What is not here

Addon execution is a sandbox with an honest failure log (`qa/out/addon_matrix.tsv` after the Lua suite). A file that loads is not a working addon. Map brushes collide. Displacement collision does not. Water, ladders, and ducking are absent.

`gm_construct` is drawn from the local GarrysMod VPKs and the map pak. Those files are not copied into this repo. Brush faces pack the BSP lightmap (style 0, the flat page on bumped faces) into one atlas. The vertex stores that luxel coordinate and the fragment shader samples it, so a dark corner does not fill the polygon. Props stay fullbright. Brush entities (`func_brush`, glass, the color room) are stored around their entity origin and drawn there. Vehicle clips, triggers, and areaportals are not drawn. Static props are the reference pose of the MDL, placed with `sky_camera` scale when they sit in the 3D skybox. VVD fixups are applied so the VTX indexes the reordered vertices. The map `skyname` is drawn as the Source 2D sky cube (`gl_warp.cpp` face order) on the camera, with depth writes off, so openings show that texture. The flat `env_skypaint` clear remains where the cube is missing. The play camera uses Source `fov` 75: horizontal on a 4:3 window, widened on 16:9 so the vertical angle stays about 60°. Foliage cards with `$alphatest` discard texels below 0.7. Detail, sway, and vertex lighting on those cards are not applied. WorldVertexTransition blends `$basetexture` and `$basetexture2` by the displacement vertex alpha (0 is the first texture, 255 is the second). `$blendmodulatetexture` sharpens that alpha, and `$detail` on those materials uses Source mode 0. Displacement luxels and albedo UVs are taken from the undisplaced quad. Quads alternate diagonals the way Source does. Bump maps are not applied. Glass and refract shaders with no albedo are omitted instead of drawn magenta. Workshop GMAs from Steam's workshop/content/4000 are mounted for models, and their Lua autorun, weapon, and entity scripts run in the sandbox. Scripted weapons and the NPC list come from that Lua. HL2 weapon world models come from scripts/weapons/weapon_*.txt. The spawn frame hangs those meshes in the view: weapons on the right, NPCs on the left, large actors farther down the street. NPCs are skinned to one named sequence frame (citizens resolve idle_subtle). There is no further bone animation and no NPC AI. Lua Initialize, Think, and PrimaryAttack run once. A weapon whose PrimaryAttack records no bullet, and that defines VR_Shoot, is called once with the owner's shoot position and angles. A list weapon with no Lua SWEP and a positive damage key records one FireBullets along that aim. A white streak is one ribbon for the first recorded bullet, 160 source units along the aim. The spawn shot recorded 186 bullets and 113 streaks. Most are horizontal white bars through the right-hand gun shelves, including the upper flock, and across the grass where the lower guns sit. One bar in the upper right is diagonal: the HL2 RPG adds 128 source units of upward speed to a 300-unit aim, and that entity has no model. Spawn applies the scripted entity and calls Initialize. PhysicsInit records the solid and does not cook a model collide. PhysicsInitBox builds a box in the open solver. SetCollisionGroup stores the Source group and the tracer does not use it. CreateSound records a patch and plays no audio. Fire records the input and does not apply it. A stored phys velocity, or the entity velocity when there is no body, is one 160-unit streak. A box from PhysicsInitBox takes one engine tick, 1/66 s, in the open solver. The floor is unset, so that step does not hit the map. Entity velocity with no body is not stepped. That frame keeps 14 of 17 spawned projectiles, and 9 of those had a velocity. The nearest actor stays 701 source units. One white bar now sits in the open sky, left of the gun shelves. The HL2 RPG bar stays diagonal in the upper right because that missile has no box. The meshes are not readable as separate rockets. ScreenFade records the flag and does not draw it, so the HL2 RPG gets past that call. NULL:IsPlayer and NULL:IsNPC return false. NULL stays one object when a weapon table is copied, so the HL2 RPG think no longer calls SetPos on a fake copy. There is still no laser-dot model. A standing player's GetVehicle is NULL, and the toolgun has no mode selected, so that attack returns. NetworkVar treats a string in the slot position as the name and uses the next free slot for that type, so the homing launcher installs GetReloading. A trace keeps StartPos. DrawShadow records the flag and draws nothing. Spawn runs SetupDataTables before Initialize, so that missile finishes init. PhysicsInit did not cook a collide, so the missile does not move. The shot draws the mesh: 616 more triangles and one more material. It is not readable as a rocket. Think still stops on IsBot. The white bars match the previous shot. The XM25 still stops because its range field is nil. Sounds are not played. The sandbox gamemode does not tick. 39 autorun files still fail. Four weapon models are still skipped. A lit map with posed meshes, bullet streaks, and one projectile bar that has left the shelf is not Garry's Mod. Sky, nodraw, and clip faces are omitted.
